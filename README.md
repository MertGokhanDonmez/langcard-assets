# langcard-assets

Card-front images for [Langcard](https://github.com/MertGokhanDonmez/english-card-game)
premium preset decks, served via raw.githubusercontent.com.

URL scheme (see `PRESET_IMAGE_BASE_URL` in the app):

    https://raw.githubusercontent.com/MertGokhanDonmez/langcard-assets/main/preset/<deckId>/<key>.webp

Files are 3:4 WebP, 800px tall. Never rename or delete a shipped file —
installed apps download by exact name.
